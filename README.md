# Basic Cybersecurity Policy

## Objective
To understand organisational security controls and create a basic cybersecurity policy for a small organisation.

## Key Security Areas
- **Password Security:** Use strong, unique passwords and enable MFA.
- **Device Security:** Lock devices and install security updates.
- **Email Security:** Avoid suspicious links and attachments.
- **Incident Reporting:** Report security incidents immediately.

## Tools Used
- Google Docs
- GitHub

## Approach
The policy was created using Google Docs and exported as a PDF.

## Outcome
A basic cybersecurity policy was developed to improve security awareness and protect organisational information.

## Deployment Configuration
This is a documentation project and does not require software deployment.

## Rollback Evidence
No deployment rollback was performed. Previous file versions can be reviewed through Git history.

## Conclusion
This project establishes basic security guidelines for a small organisation.
